# Maker AI Website Context

Core glossary defining the terms and concepts for the Maker AI website interface, brand identity, and theme system.

## Language

**Option A (Modern Enterprise Cyber)**:
The primary dark-theme brand option featuring deep space-black backdrops, neon cyan/teal accents, and high-specular glassmorphic cards.
_Avoid_: Dark mode, Cyberpunk theme

**Option B (Clean Minimalist Tech)**:
The secondary light-theme brand option featuring alabaster-white backdrops, charcoal typography, and electric indigo highlights.
_Avoid_: Light mode, Minimalist theme

**Mi Tools**:
The client-facing suite of automation, security, and ERP workspace applications hosted by Maker AI.
_Avoid_: Workspace tools, Maker tools
